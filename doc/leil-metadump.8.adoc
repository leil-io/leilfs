leil-metadump(8)
=================

== NAME

leil-metadump - a networking, distributed, highly available file system

== SYNOPSIS

[verse]
*leil-metadump* 'metadata_file'...

== DESCRIPTION

*leil-metadump*
dumps file system metadata into specified file.
